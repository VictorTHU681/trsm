# 2026-09-13：融合 Strassen 与 TC1 回写时序

生产基线为 `b138512:trsm.c`；根目录算子和官方 bench 不变。
本目录研究一次调用内的算法变换，不复用上一调用的矩阵值、打包值或任务表。
工作区只保留分配容量，每次乘法重新打包所有实际读取的输入，并重新计算全部输出。

`bash probe/fused_20260913/rebuild.sh` 重建 `generated/` 中的源码：

- `fused-pack.h` 从当前 LD4 + SME 转置内核生成加法/减法版本，加减在寄存器中完成。
- `fused.c` 实现普通矩阵乘法和一层 Strassen；七个叶子的结果直接更新一个或两个 C 子矩阵。
  支持 alpha=±1、beta=0/1；beta=0 时每个目标由第一项完整初始化，不读取旧 C。
- `driver.c` 使用独立 53 位输入，同址换数据，交替测试普通乘法与融合 Strassen；核对实际层数/叶子数。
  小矩阵逐元素检查，大矩阵检查规则坐标及首尾/分块边缘；每次检查 C 填充和输入指纹。
- `pack_boundary.c` 为两个输入和输出添加保护页，逐元素精确核对加/减转置与 B 加/减打包。
- `recursive_trsm.c` 是研究包装：完整求解 L11，执行 B2 -= L21*X1，再完整求解 L22。
  `TRSM_FUSED=0` 返回生产基线，`TRSM_FUSED_LEVEL=0/1` 对比普通更新与 Strassen 更新。
- `batch.c` 在一次调用内读取四个输入子块，生成七组打包数据；所有叶子共享任务队列，
  各自写独立 M 缓冲，最后合成 C。`prepare_direct.py` 再生成按输出块分配所有权的版本，
  同一线程计算该块全部七项并直接更新 C，不分配 M 缓冲。
- `prepare_front.py` 将 TC1 owner 内核的上一块回写集中到前 16/32/48 步，保留 64 步对照。
  生成器逐条核对指令多重集；64 步重建另要求原指令顺序完全一致。
  **与上一轮 407 的 front32 不同**：本轮保留 v50 的原始预取时间点，不同时分散 PRFM。
  ARM 上 64 步重建与原版的 `.text` 逐字节一致，检查记录在 433。

## 融合乘法的实测结果

以下是独占节点上的**矩阵更新组件**，不是线上成绩，也不是完整 TRSM 得分。
每项均保留 warmup 原始记录，中位数仅取后续三次同址换输入调用。
组件计时包括全部输入打包、运算与输出更新；第一次分配另记在 warmup。

| 更新形状 M×N×K | 普通乘法（427）ms | 逐叶融合（427）ms | 批量打包（429）ms | 直接回写（432）ms |
|---|---:|---:|---:|---:|
| 256×19968×256 | 1.964 | 4.734 | 3.607 | 4.225 |
| 1216×17024×1216 | 14.709 | 22.621 | 19.654 | 19.522 |
| 8512×512×8512 | 20.580 | 27.637 | 21.915 | 22.710 |

TC3 批量打包将 A 打包从约 10.52 ms 降到 6.05 ms，但普通乘法只需约 3.85 ms。
批量方案的计算阶段约 15.2 ms（含约 0.65 ms 的输出合成），普通乘法约 16.5 ms。
节省的运算时间仍小于额外输入打包。TC2 则同时受到 B 打包及叶子运算效率影响。
430 的普通/非临时存储切换与产品交错没有改变结论；MB96/192 更慢。

432 直接回写省掉了 M 缓冲和独立合成阶段，但每个输出块必须串行执行七项，
任务不均衡及直接 C 更新也有代价。TC3 的 MB112 从约 22.71 改善到 21.79 ms，
同场普通乘法仍为约 20.36 ms。不能将临时矩阵消失等同于端到端收益。

428 完整 TRSM 两轮交替全部 PASS。普通递归更新的分解本身就有成本：
TC2 中位约 3388、TC3 约 3321 GFLOPS，低于同场生产约 4208/4136 GFLOPS；
逐叶 Strassen 更慢。因此没有把这些组件候选接入生产。

组件使用独立的 53 位输入，覆盖 alpha=±1、beta=0/1、填充步长、尾块、
无专用路径时的回退、同址换输入和互逆 2^±400 缩放。
427 的加减打包另通过 331872 次带保护页的精确比较。
大矩阵仍是抽样加边缘校验，不能表述为全矩阵或所有一般输入均已验证。

`python3 probe/fused_20260913/analyze.py` 从原始日志重建全部 CSV；
所有慢轮保留，不因偏离中位数而删除。分相计时带观测开销，只用正式 bench 的未观测轮比较得分。

输入包括非对齐地址、填充步长、正负对角、整体及逐行缩放、同址重新生成数据。
这些测试支持候选的正确性，没有把性能不确定性转变为已确认的收益。
