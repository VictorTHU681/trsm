`0624902`（v56）。生产修改只有 `trsm.c` 中的一处准入条件和相邻注释。

- **502：TC1 精简对角函数改为独立函数。** 热点 owner 函数从 0x5dc0 缩到 0x5a68 字节，
  但相对编译时关闭改动的对照约 −0.398%，没有整体收益；进一步去掉输出预取约 −1.738%。
  后者对角 profile 0.168→0.156 ms，主更新反而 1.018→1.041 ms。局部省时不能抵消完整任务的损失。
- **503：TC1 提前装载同线程负责的面板行段。** 每次调用只读该线程拥有的行，不读其他线程正在求解的行，
  不缓存结果。六轮同二进制对照 −4.117%，加 16 行预取 −4.618%。
  load 0.290→0.368 ms，store 0.123→0.173 ms，主更新 1.012→0.986 ms。
  这与提前装入更多未来 C 数据加重缓存压力的解释一致，但没有 PMU 数据证明具体驱逐来源。
  搬到任务函数之外的 load 单独计入 t_load，不在原 task 合计里；只按完整 bench 判断。
