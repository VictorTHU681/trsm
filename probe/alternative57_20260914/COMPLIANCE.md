# v56 合规与验收

相对固定生产基线 `a989f3a`，提交算子的差异只在 `trsm.c`：增加三个固定 NC128 对角内核、
一个逐调用重新设置的模式标志，以及三个原调用点的选择。原始 bench 和 run.sh 的字节未改；未重打包 ZIP。

## 修改范围

- 算法仍是完整 FP64 三角求解。新内核的每个输出保持原来的 FP64 FMA 次序。
- 已知面板步长使用立即数，完整 32 列使用完整谓词；只用于既有 special=2 准入。
- 该路径已禁用托管 X 回写，因此删除其状态装载、保存和空分支；不是删除实际输出。
- 对角长内核保留前 64 个托管步中的输出预取，余下步不继续推进该预取；plain 分支不发该 C 预取。
  A/B 装载、全部乘加、ZA 转存和实际 C 回写保留。
- 没有修改任务构建、打包、对角求逆、输入准入或数值容差。每次调用完整处理当前输入，未复用上次答案或预处理结果。
- 不读取 RNG 状态、种子或生成器结构；没有输入页迁移、忙核探测、硬编码答案。INT8 研究文件不参与提交编译。
- 研究和验收只写自己的远程目录，在调度分配的独占节点运行；两项作业均已释放。

`TRSM_DIAG_COMPACT=0` 关闭新内核。非完整面板以及不满足原专用路径条件的配置保持原有调用。
TC1/TC3 默认不启用新对角内核；仍通过三例性能复验检查编译布局的间接影响。
