检验的假设：将上一 ZA bank 的中间结果回写集中到当前 bank 的前 32 步，
或者将原本突发的回写读取、预取均匀分散，能否减少短 K 内核的发射/访存停顿。
保持四 FMOPA/步、KC64、行主序 C、相同的 A/B 读取范围、全部 C 更新和预取地址集合。
每个输出的 FP64 FMA 顺序不变；不使用输入规律、输入迁页或跨调用缓存。

| 变体 | 回写窗口 | 回写读取 | 预取 |
|---|---|---|---|
| control | 原始 64 步 | 每 8 步读取四个向量 | 原始突发 |
| pfspread | 64 步 | 每 8 步读取四个向量 | 每步一条 |
| spread | 64 步 | 每 2 步读取一个向量 | 每步一条 |
| front32 | 前 32 步 | 每 4 步读取四个向量 | 每步一条 |
| late32 | 后 32 步 | 每 4 步读取四个向量 | 每步一条 |

边界检查使用保护页，独立标量 FMA 参考覆盖所有 C 元素与未更新区域、独立 53 位输入及极大/极小互逆缩放。
后续已知解检查由长双精度构造 RHS，同址换输入、正负对角、填充、非对齐和 L 不变，并断言专用路径实际启用。
微基准复用已归档的 `kdup2.c` 访问模式，仅将 owner 调用切换到当前 cursor 内核；
其中报告的周期是计时器按 1.55 GHz 折算，不是 PMU 实测核心周期。
微基准吞吐不能当作完整 TRSM 或线上成绩。
